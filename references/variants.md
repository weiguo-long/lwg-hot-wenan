## 流派 A：观点锤击型（单观点深锤，情绪+机制，80-150字）

### V1 规则清单型（样本2.2万赞，收藏向，默认稳妥款）
结构：指控/设问开场 → 强者断言 → 触发规则 → 降维类比 → 行为清单 → 画面收尾
句式：
- 指控句："XX拖垮你。"
- 强者断言："成事的人都有个习惯，对XX特别利落。"
- 触发对："发现XX，马上XX。"
- 三重否定："别XX、不XX、不XX，直接XX。"
- 降维类比：生活场景翻译机制（"外卖凉了直接倒掉"）
- 类推："XX也是一个逻辑，先XX，XX立刻XX。"
- 画面收尾："直接结账走人。"
- 决策主权句式包（决策/被劝主题，催婚版4794赞验证）：
  - 排比："亲戚催你结婚，但他不会替你过柴米油盐的日子。朋友劝你辞职，但他不会替你承担亏损。同事质疑你方案，但辞职报告他不会替你去写。"（句式：XX劝你A，但他不会替你B）
  - 隐喻："每个指手画脚的人都在岸边，真正在水里游泳的只有我们自己。"
  - 定调："这是成年人的第一课。意见可以听取，选择不要盲从，决策权留给承担后果的人。"
铁律：必须含降维类比+行为清单，缺一返工。

### V2 认知抬价型（3992赞，勿单独用）
结构：断言 → 稀缺化 → 补足论 → 隐秘真相 → 低估论
句式："真正的差距只有这一个。" / "现在缺的XX，都会在XX的路上凑齐。" / "这是很隐秘的真相，不是鸡汤。" / "尽管大家都在说，它的XX还是被低估太多。"
铁律：只做点缀句，不整段抬价。

### V3 定义翻转型（3143赞，开场钩子最强）
结构：设问 → "不是A，是B" → 机制重定义 → 身份收尾
句式："XX的本质是什么？" / "不是XX，是XX。" / "本质不是你的XX，而是你背后有多少XX。" / "真正的XX始于你成为XX的枢纽。"
铁律：翻转必须推翻一个大众默认常识。

**混搭规则（A流派）**：V3开场 + V1中段 + V1/V3收尾最优；V2只配点缀。

## 流派 B：清单工具型（数字+排比，干货+自测感，150-300字）

### V4 清单提问型（1.18万赞，收藏自测向）
结构：承诺开场 → 统一排比提问 → 使用说明+底层逻辑定调
句式："敢于XX的你，事前一定会问自己这N个问题。" / "从X出发，Y？"（N条同构、逐条递增）/ "遇事拿这N条过一遍。" / "……才是成年人做事的底层逻辑。"
铁律：能用提问绝不用陈述，让观众逐条在心里自答。

### V5 清单陈述型（521赞，慎用）
同结构改陈述，除非条目自带戏剧性，否则数据掉一档。

### V12 陷阱清单型（程雪峰版3.27万赞，评论向）
结构：虚拟情景开场 → 扎心翻转 → 定调 → 逐条拆解（3-5个陷阱）→ 系统汇总 → 破局清单
逐条单元：命名要狠（名字能单独传播）+ 人群画像（"先看第一种人，他们的人生信条是……"）+ 为什么不行（一个具体天花板）+ 概念背书（稀缺心态/机会成本/延迟偏误等真实概念）+ 金句收条
汇总句："X个陷阱叠起来，构成一套XX系统……你一直在玩一个赢不了的局。"
铁律：条目必须是大众默认合理的反面行为；概念背书+金句双件套；禁止编造概念名。

### V15 训练营清单型（26.1万赞，行动向）
结构：承诺开场 → 逐条练习 → 中段嵌真实案例 → 金句收尾
句式："死磕这N件事，X天练出XX。" / 每条=概念定义+普通人vs内行人视角对比+"今天立刻能做的具体动作"（拆账单/观察20分钟/拆解3件东西）+收益节点（坚持两周后/一个月后）
收尾："最难的门槛不是资金，不是资源，是XX。"
铁律：每个动作必须"今天就能做"且具体可执行；用"XX的眼睛 vs XX的眼睛"视角对比贯穿。

**V15b 轻条目清单模式**（张慕瑶"闷声干10件事"6.5万赞，数字清单赛道，同类天花板37.5万赞/30条）：
- 开场承诺："你照着做，未来一定会感谢今天狠心对自己的这一刻。"（狠心/闭嘴/低头）
- 条目结构（每条≤80字三明治）：动作指令（"若无社交诉求不要向外展示"）+ 机制理由（"豪车名表只会给你'混得还不错'的错觉，然后心安理得停在原地"）+ 金句收条（"低配的生活，高配的能力"）
- 金句库（可复用）："人脉的本质是价值交换，没有筹码，所有关系都是消耗。" / "短剧设计出来就是为了让你上瘾的。" / "两小时的专注力抵过瞎忙一整天。" / "省下的每一分钱都是选择权的种子。" / "把自己变成一个值钱的人，是你开始有选择权的起点。"
- 收尾："不需要任何背景、天赋、资源，只需要你闭嘴低头去死磕，时间会给你答案。"
铁律：条目越多每条越轻（10条≈50-80字，30条≈30-40字）；每条必须含动作+机制+金句三明治；数字清单赛道收藏动机强（确定性承诺）；"闷声/低调/别晒"主题优先用本模式。

## 流派 C：格言宣言型（金句密度，100-200字）

### V6 格言堆叠型（6909赞/512评论，评论率最高）
结构：设问开场 → 对仗双重否定 → 金句连发 → 高位收尾
句式："为什么X最终由Y决定？" / "XX不够，就算A再强也会被困在B里。YY不足，哪怕C拼命也只能拿到D。" / 对偶句"谋事要有见识，做事要有胆识。" / 敢字诀"敢想别人不敢想。" / 本质定调"畏惧失败本质上就是在拒绝成功。" / "想要拿到X，就要拥有Y。"
铁律：金句密度是灵魂，每2句必有一个可截图的句子，全篇≥3个。

**V6b 金钱观双评价分支**（"掌控金钱"文案多版本搬运，最高6973赞/421评论，存钱赛道箴言体）：
- 断言："能掌控金钱的人，才能掌控人生。"（掌控X→掌控Y因果断言）
- 双评价："会赚钱是本事，会存钱才是清醒。"（"会X是本事，会Y才是清醒/智慧"抬价格式）
- 反面恐吓："如果只知道花钱，不懂得存钱，就算赚的再多，结局也难免凄凉。"（赚得多→凄凉反转）
- 正面补偿："会合理规划钱的人，就算赚的少，他的生活也能有滋有味。"（赚得少→有滋有味再反转）
- 同源变体："赚钱是能力，存钱是智慧。不然你收入再高，不懂储蓄终会陷入窘迫。你手里有积蓄，心中才能有底气。"
铁律：双评价必须"会X是本事/能力，会Y才是清醒/智慧"（把老生常谈抬到智慧层级）；双反转必须"赚得多→坏结局 vs 赚得少→好生活"对照；整条≤100字可整段截图；多版本搬运验证（不同账号同文案同火，适合素材混剪或文字卡点）。

## 流派 D：故事案例型（200-400字，2.7万赞天花板）

### V7 故事案例型
结构：挑衅断言（预判反感）→ 概念重定义 → 底层机制 → 真实案例×2-3 → 金句拔高 → 高位收尾
句式："你可能觉得这太绝对，但这就是最顶级的X。" / "真正的X不是A，是B。" / "先把自己活成X，再去遇见Y。"
铁律：案例必须有具体人物、细节、对话、数字；案例结尾各落一句金句。

## 流派 E：对话哲理型（对白体，200-500字，需"智者"角色设定）

### V8 犀利拆解对话（34赞，慎用）
结构：场景点名开场 → 凡人嘴替反驳 → 概念重命名 → 机制深挖 → 第二轮回合 → 落地建议 → 温情反转收尾
句式："又在发你精致的朋友圈了。" / "这叫选择性的真实，是一种高级谎言。" / "自我价值的定价权被交给了观众，这是自我物化。" / "你现在有一个了。"
铁律：每轮交锋至少产出一个可截图的金句或命名；凡人必须替观众说真实困惑。

### V9 宽慰哲理对话（5299赞，远好于V8）
结构：凡人抛痛点 → 翻转设定 → 浪漫因果解释 → 金句收心 → 画面承诺 → 高位收尾
句式："为什么好人总是没好报？" / "宇宙的账本不是这样记的。" / "善意不会消失，只是换了形式流向别处。" / "这个你就是回报。" / "你活着本身就是光。"
铁律：选题优先"人人心里都有的意难平"，不选猎奇。

## 流派 F：情绪宣言型（第一人称独白，60-150字，个人IP/情绪赛道）

### V10 宣言独白（全网搬运级）
结构：宣言开场 → 三重否定排比 → 课题分离 → 不背负宣言 → 轻收尾
句式："我做过最好的决定是XX。" / "我不会说服任何人XX / 我不会修补任何XX / 我不会争取任何人XX。" / "你想做什么是你的事，我要做什么是我的事。" / "我也不背负任何人的XX。" / "自由、平静地一路向前。"
铁律：全程第一人称"我"；只写否定句和边界句，不写建议不写机制；让观众产生"这就是我想说的"代言感。

## 流派 G：深度论证型（长文案，证据链，天花板最高）

### V11 核心隐喻论证（18.68万赞）
结构：提问开场 → 建立核心隐喻（贯穿全篇）→ 权威背书 → 历史案例×2 → 机制深挖 → 行业案例×2-3 → 行动清单×3
铁律：隐喻必须"一句话说透+自带画面感"（卖铲子）；证据链真实可查（人名/书名/数据）；每30秒一个新案例或概念撑完播。

### V13 对比故事论证（信息差，抽象概念具象化首选）
结构：扎心提问 → 极简答案（"就两个字：X"）→ 对比故事（小A vs 小B，同场景同起点两种做法）→ 点题金句（"A在追着天气跑，B却在需求前面等着"）→ 反面清单×3 → 正面清单×3 → 金句收尾
铁律：A/B只差一个变量；点题金句用动作对比；先给答案再讲故事。

### V14 分层递进论证（38.2万赞，全部样本天花板）
结构：三人对比开场（反面人+正面人+中间人=观众同类）→ 定调金句（"你不是赚的太少，是花的姿势不对"）→ 分层递进（第一层/第二层/第三层，每层=新概念+学术概念背书+真实案例或实验+层内小结论）→ 落地清单×3 → 权威金句收尾
铁律：中间人必须有（代入钩子）；每层带"概念+案例"双件套；显性编号制造完播欲。

## 流派 H：毒鸡汤反转型（丧文化段子，高评论率）

### V19 毒鸡汤反转型（2.06万赞/评论率7.4%）
结构：鸡汤庄严句式开场 → 逐句反转（5-8句）→ 谐音双关 → 递进式绝望收尾
句式："好好活下去。" / "相信自己，你还有很大的下降空间。" / "上帝关上一道门，还会给你关上一扇窗。" / "你每天都很困，为什么？因为你被生活所困。" / "人生不过就是起起落落落落落。"
铁律：前半句庄严鸡汤、后半句急转弯；反转永远损自己不损别人；每句能单独截图当段子。

## 流派 I：第一性原理链条型（思维游戏，2.6万赞+全网搬运）

### V20 第一性原理链条
结构：总起句 → 连锁链5-7环 → 升华收尾
句式："XX的第一性原理。" / 每环"A的第一性原理是B，不是C"，下一环从B继续下钻 / 收尾"XX的终点不是没有X，而是在别人看不见的地方建立Y。"
铁律：环环相扣；每环必须带"不是"对立（对立项是大众默认俗见）；总长≤150字；结尾必须升华。

## 其他高传播变体

### V16 互动倒推型（19.2万赞/6.85万评论，互动之王）
结构：灵魂提问+互动指令 → 激将骂醒 → 机制拆解 → 真实案例 → 倒推四步 → 三坑提醒 → 互动收尾
句式："你这一生打算赚多少钱？把数字写在评论区。" / "说不出来那你创什么业？全是怂。" / "数字会逼着你做选择。" / 倒推四步：定数字（月收入×5-10倍）→除以12→拆每日动作→最小成本跑第一单 / "评论区写下你的数字，你敢写我就敢帮你拆。"
铁律：开头和结尾各埋互动指令；激将打在"不敢"上不人身攻击；结尾给"我会回应你"的承诺。

### V17 时代窗口盘点型（11.3万赞）
结构：惊爆开场 → 规律宣称 → 时间轴盘点（5-6次，每次起名：胆量红利/产能红利/流量红利…）→ 当下窗口三依据 → 门槛压到最低的机会定义 → 紧迫收尾
铁律：每次窗口必须起名；结尾制造"错过就没"的紧迫感；时代叙事只讲发展历程与商业机会。

### V18 认知纠偏+实操清单型（23.9万赞）
结构：开宗明义 → 认知纠偏（"还在纠结X，说明你还是学生思维"）→ 本质一句 → 原则清单 → 实用方法×2 → 替焦虑人群预设问题（"如果我一无所有，我会怎么做"）→ 共情收尾
铁律：纠偏打在观众默认认知上；方法落地到动作；收尾共情优先于打鸡血。

### V21 边界智慧型（11.35万赞/2152评论，全网多版本，人际边界赛道）
结构：断言定调 → 身份否定 → "暴露→拿捏"机制 → 痛点场景 → 招式×2（话术型）→ 总结定调
句式：
- 断言："有问必答是人际交往的大忌。"
- 身份否定："你不是奴才，不是谁的小跟班，凭什么被别人牵着鼻子走。"（解绑"礼貌绑架"）
- 机制："别人问什么你答什么，别人就很容易知道你的弱点，然后用这些弱点来对付你。"
- 痛点场景："碰到让你不舒服的问题，不要着急回应。"
- 招式："第一招，目光审视——上下打量对方，夺回主动权。第二招，以问代答——'你这个问题很有意思，你为什么这么问？'"
- 定调："很多越界的问题本质就是一种试探，你回答的越多越容易被别人拿捏。"
铁律：招式必须给"能直接背下来用的话术"（万能回应句）；身份否定打在"礼貌绑架/老实人思维"上；机制必须讲清"暴露→拿捏"链路；结尾定调把主题上升为"试探本质"；蹭热点式开头可用"告诉孩子/你从什么时候才明白"。

### V22 减法聚焦型（12.2万赞/1003评论，全网5+版本搬运，vibe知识大赏官方话题）
结构：悬念提问开场（焦虑+承诺双钩）→ 双权威案例×2（都指向同一动作）→ 机制点题 → 减法清单 → 金句 → 首尾呼应提问收尾
句式：
- 悬念开场："如果你已经落后了同龄人5年，你还能不能在半年内追回来？"（落后X年/差距，多久能追上）
- 权威案例："巴菲特曾让飞行员写下25个人生目标，再圈出最重要的5个……那20个是你拼了命也要避开的陷阱，这叫5/25法则。"（人名+具体场景+概念命名）
- 第二案例："乔布斯重回苹果，第一件事就是砍掉70%的业务，只留4款产品。"（案例必须同样指向"减法"）
