# 变体 → 视频制作方式映射表

> 生成文案后必查本表，输出制作方式建议（首选+备选+一句理由）。
> 选择逻辑：结构决定方式——金句密度高走 vibe/文字卡点，层级链条走投屏，有对白走对话，有案例走小剧场，强互动走真人口播。

## 制作方式定义

| 方式 | 说明 | 适用信号 |
|---|---|---|
| 口播直述 | 真人出镜直接说，画面以人为主 | 强观点 / 强互动 / 信任感 |
| 数字人口播 | 虚拟形象说话（AIGC低成本） | 无真人条件 / 批量生产 |
| vibe知识大赏 | 高清大素材 + 大字幕卡点 + 氛围音乐，无人出镜 | 金句流 / 情绪流 / 观念感 |
| 对话演绎 | 双角色对白（真人或分饰/AI配音） | 文案含对白结构 |
| 故事小剧场 | 情景演绎完整故事（真人/动画/微剧） | 故事 / 案例 / 对比 |
| 投屏演示讲解 | PPT/白板/思维导图/流程图/时间轴，配合讲解 | 层级 / 链条 / 列表 / 数据 |
| 图文轮播 | 图片 + 文字翻页（抖音图文） | 清单 / 收藏向 |
| 文字卡点 | 纯字幕逐句弹出卡节奏，无解说或轻解说 | 段子 / 反转 / 短金句 |
| 素材混剪 | 历史影像/资料画面剪辑 | 时代 / 盘点 / 事件 |

## 指标-方式兜底规则

- 目标指标为**收藏** → 优先投屏演示/图文轮播（信息密度）
- 目标指标为**评论/转发** → 优先口播/对话演绎（人感驱动表态）
- 目标指标为**完播** → 优先投屏（层级可视化）/文字卡点（节奏）
- 无真人条件 → 数字人口播 或 vibe/文字卡点替代口播

## 制作要点（通用）

- vibe知识大赏：素材选高清大场景/微观细节，字幕单句居中，卡点对 BPM，一条视频只配一个氛围情绪。实例（怪知识V22样本12.2万赞）：悬念提问大字幕开场，权威案例/概念名（5/25法则）加粗弹出，减法清单逐条"划掉"动效，结尾提问字幕定格；标题挂「Vibe知识大赏」话题标签（官方流量池），无人出镜、文案可跨账号搬运

## vibe知识大赏制作方法论（怪知识创作者亲述，1.08万赞拆解）

- **选题规律**：能用「你」字开头问出反常识问题（"你在上海发照片，洛杉矶朋友0.07秒收到，它是怎么过去的"）——一个每天碰到的现象背后藏着一个原理。科普/心理学/诺贝尔奖类最适合；金融/历史类因果链太长，观众看一半就走
- **开头规律**：第一帧画面必须完整（禁止黑屏慢慢亮起）；第一句话直接把反常识问题甩出来
- **画面规律**：每个画面变化必须跟上字幕——字换了画面不动超过2秒，观众必走，且感觉制作粗糙
- **制作方式**：AI写代码渲染3D动画（不是文生视频模型），画面清晰、文字不乱码、可逐秒修改、风格可复用
- **提示词结构**：通用提示词（字幕多大/每句停几秒/画面怎么动）+ 内容提示词（主题/分镜/字幕稿）
- **流程**：先让AI出15秒样片，满意后再做全片，避免返工浪费时间
- **配乐**：vibe的灵魂，优先用"别人用起来流量高"的热门BGM
- **预期**：爆与不爆差200倍，不爆是常态，爆了是惊喜——保持心态，同一套方法不是每条都爆
- 投屏演示：一屏一概念，箭头/编号必须和文案递进严格同步
- 对话演绎：两角色音色区分明显，镜头在两人间切
- 文字卡点：字要大、留白多，每句独立一帧，反转句前停半拍
